# REQ-BUILD-002. Самотестирование перед выпуском

## Формулировка

Перед выпуском все группы автоматических проверок (`MurikDNS.exe --self-test`) должны быть пройдены трижды подряд.

## Обоснование

Снижение риска регрессий.

## Критерии приёмки

- Три отчёта самотестирования с результатом Ok.

## Метод верификации

Тест

Проверка: три прогона self-test. Свидетельство: self-test-1.json, self-test-2.json.
