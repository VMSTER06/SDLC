# REQ-INT-005. Формат списка профилей

## Формулировка

Список профилей должен храниться в файле JSON, где каждый профиль задаётся полями Name (строка), Addresses (массив IPv4-адресов) и Doh (URL шаблона DoH).

## Обоснование

Адреса провайдеров меняются; список обновляется без изменения кода.

## Критерии приёмки

- Файл с 15 профилями загружается.
- Профиль с некорректным IPv4-адресом отвергается при загрузке.

## Метод верификации

Тест

Проверка: self-test, core. Свидетельство: self-test-1.json.
