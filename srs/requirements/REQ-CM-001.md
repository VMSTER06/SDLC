# REQ-CM-001. Изменение требований через pull request

## Формулировка

Изменения требований должны вноситься через pull request в репозиторий с повышением версии документа, суффиксом версии у изменённых требований и записью в истории изменений.

## Обоснование

Трассируемость решений Заказчика.

## Критерии приёмки

- Каждая версия документа соответствует коммиту и записи в истории изменений.

## Метод верификации

Инспекция

Проверка: история коммитов. Свидетельство: —.
