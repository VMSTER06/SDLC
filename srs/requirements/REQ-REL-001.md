# REQ-REL-001. Откат при ошибке

## Формулировка

Если применение профиля завершилось ошибкой, система должна автоматически восстановить оригинал адаптера.

## Обоснование

БЦ-3.

## Критерии приёмки

- Тест с подставной сетью, возвращающей ошибку, — настройки равны исходным.

## Метод верификации

Тест

Проверка: self-test, FakeNetwork. Свидетельство: self-test-1.json.

## Дополнительная информация

рисунок 4.

Спецификация: [srs-murikdns.md](../srs-murikdns.md).
