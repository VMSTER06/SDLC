# REQ-SEC-003. Архив без личных данных

## Формулировка

Архив для распространения не должен содержать настроек, сохранённых оригиналов и журналов автора.

## Обоснование

БЦ-5.

## Критерии приёмки

- В архиве отсутствуют файлы из каталога данных пользователя.

## Метод верификации

Инспекция

Проверка: archive-test. Свидетельство: archive-test.json.
