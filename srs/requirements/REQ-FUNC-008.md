# REQ-FUNC-008. Результаты для каждой сети

## Формулировка

Система должна сохранять результаты последнего подбора и лучшие профили отдельно для каждой сети и показывать их при возврате в эту сеть.

## Обоснование

БЦ-2 — в разных сетях лучший DNS разный.

## Критерии приёмки

- После переключения между двумя сетями в таблице показываются результаты соответствующей сети.
- При отсутствии данных выводится «Сохранённых результатов для этой сети нет».

## Метод верификации

Тест

Проверка: self-test, benchmarks. Свидетельство: self-test-1.json.
