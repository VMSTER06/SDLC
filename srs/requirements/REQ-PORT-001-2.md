# REQ-PORT-001-2. Поддерживаемые платформы

## Формулировка

ПО должно работать в Windows 11 x64 со всеми функциями; в Windows 10 x64 ПО должно подключать профили как обычный DNS без системного DoH и показывать режим «DNS» вместо «DoH». Другие ОС не поддерживаются.

## Обоснование

CON-1; уточнено по замечанию З-4.

## Критерии приёмки

- Все тесты проходят в Windows 11 x64.
- В Windows 10 x64 подключение выполняется, на главной странице выводится «/ DNS».

## Метод верификации

Тест

Проверка: self-test; Windows 10 не проверялась. Свидетельство: self-test-1.json.
