# REQ-BUILD-001. Сборка без предупреждений

## Формулировка

Выпуск должен собираться скриптом `Build-Cpp.ps1` (CMake, Ninja, MinGW GCC) с флагами `-Wall -Wextra -Wpedantic -Wconversion` без предупреждений.

Качество и воспроизводимость сборки.

## Критерии приёмки

- Журнал сборки не содержит предупреждений и ошибок.
