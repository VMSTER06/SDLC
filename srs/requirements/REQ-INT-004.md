# REQ-INT-004. Взаимодействие с Windows и сетью

## Формулировка

ПО должно читать и изменять настройки DNS, DoH и IPv6 адаптера средствами Windows (IP Helper, WMI, netsh), выполнять DNS-запросы по UDP 53 (RFC 1035) и DoH (RFC 8484), HTTPS-запросы GET `/cdn-cgi/trace` к chatgpt.com и claude.ai через TLS-модуль Windows (Schannel), а автозапуск регистрировать в Планировщике заданий Windows.

## Обоснование

CON-1, CON-3 — используются только штатные средства Windows.

## Критерии приёмки

- На Windows 11 x64 без дополнительного ПО все операции выполняются.
- При отсутствии TLS-модуля выводится сообщение «Не найден TLS-модуль Windows».

Проверка: self-test, inspect. Свидетельство: self-test-1.json.
