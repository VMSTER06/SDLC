# REQ-FUNC-002-3. Критерий выбора лучшего профиля

## Формулировка

Система должна считать профиль доступным, если через него разрешено имя и получен HTTPS-ответ от каждого сервиса из списка проверки (REQ-FUNC-017; по умолчанию chatgpt.com и claude.ai), и упорядочивать доступные профили по возрастанию оценки S = t_DNS + Σ t_i + 0,25 · t_ping, где t_i — задержка HTTPS-ответа i-го сервиса, все t — в миллисекундах (при отсутствии ответа на ping t_ping = 0). При равных оценках профили упорядочиваются по названию.

## Обоснование

БЦ-2; уточнено по замечанию З-1 (версия 2) и обобщено на список сервисов в раунде 2 (версия 3).

## Критерии приёмки

- Недоступные профили не получают отметку «Лучший».
- три профиля с наименьшей оценкой отмечаются «Лучший #1», «Лучший #2», «Лучший #3».
- для набора измерений из теста порядок совпадает с расчётом по формуле.
