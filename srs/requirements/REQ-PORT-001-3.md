# REQ-PORT-001-3. Поддерживаемые платформы

## Формулировка

ПО должно работать в Windows 11 x64 со всеми функциями. Другие версии Windows и другие ОС не поддерживаются; при запуске на Windows 10 ПО должно сообщить «Требуется Windows 11» и завершиться без изменения сети.

## Обоснование

CON-1; уточнено по замечанию З-4 (версия 2); поддержка Windows 10 отменена Заказчиком в раунде 2 (версия 3).

## Критерии приёмки

- Все тесты проходят в Windows 11 x64.
- на Windows 10 выводится сообщение и настройки сети не изменяются.
