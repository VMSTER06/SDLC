# REQ-FUNC-002-2. Критерий выбора лучшего профиля

## Формулировка

Система должна считать профиль доступным, если через него разрешено имя и получен HTTPS-ответ от chatgpt.com и claude.ai, и упорядочивать доступные профили по возрастанию оценки S = t_DNS + t_ChatGPT + t_Claude + 0,25 · t_ping, где t — задержки в миллисекундах (при отсутствии ответа на ping t_ping = 0). При равных оценках профили упорядочиваются по названию.

## Обоснование

БЦ-2; уточнено по замечанию З-1: «лучший» должен проверяться числом.

## Критерии приёмки

- Недоступные профили не получают отметку «Лучший».
- Три профиля с наименьшей оценкой отмечаются «Лучший #1», «Лучший #2», «Лучший #3».
- Для набора измерений из теста порядок совпадает с расчётом по формуле.

## Метод верификации

Тест

Проверка: self-test, rank. Свидетельство: self-test-1.json.
