# REQ-INST-001. Переносная поставка

## Формулировка

Программа должна запускаться из распакованной папки выпуска без установщика и без установки .NET, Python и Qt.

## Обоснование

БЦ-5, CON-3.

## Критерии приёмки

- Запуск с очищенной переменной PATH на чистом ПК Windows 11 x64.

## Метод верификации

Тест

Проверка: запуск с чистым PATH. Свидетельство: —.
