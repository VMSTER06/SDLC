## Описание проекта

«Калькулятор жизни» – настольное приложение с графическим интерфейсом,
которое по введенному стажу работы за компьютером (количество лет и часов в день)
рассчитывает статистику: общее время за компьютером в часах и днях,
пробег курсора мыши в километрах, количество кликов и нажатий клавиш.

Приложение строится по архитектурному паттерну MVC с активной моделью:
модель сама проверяет данные, выполняет расчет и уведомляет представление
об изменениях с помощью сигналов Qt.

В ходе дисциплины на этом проекте отрабатываются этапы жизненного цикла ПО:
спецификация требований (SRS), проектирование (SDD, ADR), реализация,
тестирование и сопровождение.

## Технологии

- язык C++17;
- фреймворк Qt 6.7 (модуль Widgets);
- система сборки CMake, генератор Ninja;
- среда разработки Microsoft Visual Studio 2026, компилятор MSVC.

## Структура репозитория

| Каталог | Назначение |
|---|---|
| `project/LifeCalculator` | Исходные тексты учебного проекта |

| `adr` | Шаблоны записей архитектурных решений |
